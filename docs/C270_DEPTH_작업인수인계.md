# JETANK C270 Depth 작업 인수인계

팀원의 2026-11-04 CSI 카메라 실험을 검토한 뒤 진행한 C270 작업과 후속 보정 절차를 정리했다. 목표는 **렌즈 중심부터 표적 표면까지의 직선거리를 1m 이내에서 ±1cm 오차로 추정**하는 것이다. 실시간 영상, 영역 선택, 실측 기록은 구현했다. 현재 거리 정확도는 목표에 미달한다.

## 1. 팀원 작업과 이어받은 방식

- 팀원은 JETANK의 **300×300 CSI 카메라**를 체커보드로 렌즈 보정했다. ZIP의 원본 NPZ에는 보정에 사용한 24장, 내부 코너 14×9, 재투영 RMS 약 0.334px가 기록돼 있다.
- Depth Anything V2 Metric ViT-S로 원본과 왜곡 보정 입력을 비교했다. 갈색 공책에 한정한 0.20~0.80m 선형 보간은 별도로 둔 70cm 표본 8프레임에서 평균 절대 오차 5.03cm였다.
- C270에서 이어받을 방식은 **동일 거리에서 여러 프레임 수집**, **원본과 왜곡 보정 입력 비교**, **보정에 쓰지 않은 표본으로 검증**이다. CSI의 렌즈 행렬과 공책 보간 계수는 CSI 영상과 해당 모델에 종속된다.
- 참고 자료는 `2026-11-04_Notion_개발일지.pdf`와 `JETANK_calibration_code_20261104.zip`이다.

## 2. 이후 진행한 작업

| 작업 | 결과 |
| --- | --- |
| C270 연결 확인 | JETANK USB의 `/dev/video1`에서 640×480 프레임 수신을 확인했다. 기존 CSI는 `/dev/video0`이었다. 재부팅 후 장치 번호는 다시 확인한다. |
| 영상 송출 | JETANK에서 최신 JPEG 한 장을 보관하고 지정된 PC에 스냅샷을 제공한다. PC에서 받는 주소는 시연 당시 `http://70.12.231.81:8766/frame.jpg`였다. |
| 실시간 Depth | PC GPU에서 Depth Pro 추론. [영상 및 측정 화면](http://127.0.0.1:8001/video)에 C270 원본과 깊이 지도를 표시한다. |
| 초기 내참수 | 첫 프레임에서 얻은 초점거리 추정값을 실행 세션 동안 고정하고, 주점을 영상 중심으로 가정했다. 실측 기록에는 799.551px와 802.086px 두 세션이 있다. C270 체커보드 보정은 미완료다. |
| 거리 기록 | 프레임을 고정하고 표적 영역을 드래그하면 픽셀별 렌즈 직선거리의 중앙값을 계산한다. 실측 입력과 함께 원본 영상, 깊이 배열, 선택 좌표, 프레임 번호를 저장한다. |
| 버튼 수정 | cm 입력의 HTML 간격 제한을 수정했다. 실제 화면에서 60cm 입력으로 버튼 활성화를 확인했고, 사용자가 저장한 실측 기록도 파일로 확인했다. |
| 시험 보정 | 나무색 벽면 선택 영역에만 사용자가 체크해서 볼 수 있는 차감 보정을 추가했다. |

광축 깊이 Z와 렌즈 직선거리 R은 별도로 저장한다. R은 각 픽셀의 Z와 내참수를 사용해 계산하고, 선택 영역의 유효 픽셀 중앙값으로 실측과 비교한다.

## 3. 보정 시험 결과

802.086px 세션의 벽면 60cm와 80cm 기록(#6587, #6668)을 사용했다. 두 표본의 평균 과대 추정은 **20.0627cm**다. 시험 보정은 원본 추정에서 이 값을 뺀다. 화면의 적용 조건은 C270 640×480, 같은 추정 내참수 프로파일, 같은 초점거리, 원본 추정 범위 80.39~99.74cm, 사용자 체크다. 보정은 영역의 표시 숫자에만 적용하고 CSV에는 원본 추정값을 남긴다.

| 역할 | 프레임 | 실측 | 원본 추정 | 보정 후 | 보정 후 오차 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 보정에 사용 | 6587 | 60.00cm | 80.39cm | 60.32cm | +0.32cm |
| 보정에 사용 | 6668 | 80.00cm | 99.74cm | 79.68cm | −0.32cm |
| 최초 독립 검증 | 7640 | 70.00cm | 91.77cm | 71.70cm | +1.70cm |
| 추가 검증 | 14939 | 70.00cm | 98.15cm | 78.08cm | +8.08cm |
| 추가 검증 | 15317 | 60.00cm | 84.44cm | 64.38cm | +4.38cm |
| 추가 검증 | 15422 | 80.00cm | 141.78cm | 적용 범위 밖 | — |

팀원의 보간 방식을 C270의 같은 60·80cm 두 점에 시험했을 때 최초 70cm 표본은 **71.76cm**, 오차는 **+1.76cm**였다. 최초 70cm 표본은 두 방식 모두 ±1cm를 넘었다.

같은 802.086px 세션에서 80cm의 추정값은 **99.74·107.64·141.78cm**였다. 이 값은 서로 다른 기록에서 나온 수치이며, 카메라와 표적을 고정했을 때의 연속 프레임 편차는 아직 측정하지 않았다. 추가 기록에서 사용한 영역도 서로 다르다. 최종 80cm 기록은 사용자가 전달한 `depth_unvalidated (3).npz`와 파일 내용까지 일치한다.

## 4. 다음 작업자가 진행할 보정 절차

1. **재현성부터 측정한다.** 카메라를 고정하고 무광 평판을 60·70·80cm에 둔다. 평판 위의 같은 기준점을 실측하고, 같은 위치와 크기의 영역을 선택한다. 조명과 카메라 방향을 유지하며 거리마다 연속 추론 프레임 8장을 기록한다. 현재 화면은 한 번에 한 장을 저장하므로 수동으로 반복하거나 8장 묶음 기록을 추가한다. 고정 화면을 다시 저장하는 방식은 피하고 프레임 번호가 달라졌는지 확인한다.
2. **렌즈 보정값을 따로 만든다.** 실제 사용할 C270 640×480 설정에서 체커보드를 중앙과 모서리, 여러 거리와 각도로 촬영한다. 내부 코너 수와 실제 한 칸의 길이를 기록하고 OpenCV로 C270 전용 K와 D를 계산한다. 보정 파일은 `config/c270_calibration.json` 경로로 연결하도록 실행 환경을 설정한다. 렌즈 보정 품질은 재투영 오차로, 거리 품질은 별도 실측으로 평가한다.
3. **동일한 원본 프레임으로 두 입력을 비교한다.** 원본 영상과 왜곡 보정 영상을 각각 Depth Pro에 넣는다. 보정 영상에는 보정 후 행렬을 사용한다. 원본 영상에서 렌즈 직선거리를 계산할 때는 원본 픽셀의 왜곡을 고려해 광선을 계산한다. 두 경우 모두 같은 표면을 가리키는 영역에서 거리 순서, 고정 장면 편차, 독립 표본 오차를 비교한다.
4. **재현되는 범위에서 거리식을 맞춘다.** 사용 거리 안에서 측정점을 늘리고, 거리마다 모은 값의 중앙값으로 차감식이나 1차식을 비교한다. 거리 순서가 반복해서 뒤집히거나 같은 거리의 편차가 허용 오차를 넘으면 계수를 늘리기 전에 입력·표적 조건이나 측정 방식을 재검토한다.
5. **별도 촬영으로 합격 여부를 결정한다.** 같은 장면의 연속 프레임을 보정용과 검증용으로 나누는 대신, 카메라나 표적을 다시 배치해 독립 검증 세트를 만든다. 실제 사용할 표적·거리·화면 위치를 포함하고, 최대 절대 오차와 거리별 반복 편차를 기록한다. 검증 표본마다 절대 오차가 1cm 이하여야 통과다. 모델 추정이 이 수준을 반복해서 충족하지 못하면, 크기를 아는 마커나 거리 센서처럼 절대 거리 기준이 있는 방식으로 검증한다.

## 5. 코드와 데이터 위치

프로젝트 루트는 `D:\Embedded\AGV PJT`다.

| 위치 | 내용 |
| --- | --- |
| `robot/c270_snapshot.py` | JETANK C270 JPEG 송출 |
| `scripts/start-video.ps1` | PC 웹 서버 실행, 스냅샷 입력 지원 |
| `depth/worker.py` | Depth Pro 추론, Z와 R 계산 |
| `backend/depth_api.py` | 프레임 고정, 영역 추정, 실측 기록 |
| `frontend/video.html`, `frontend/depth.js` | 영상 화면, cm 입력, 시험 보정 체크박스 |
| `data/depth_evaluation_c270/measurements_v4.csv` | C270 실측 원장, 확인 시점 15건 |
| `data/depth_evaluation_c270/` | 표본 ID별 NPZ, 원본·처리 영상, JSON 메타데이터 |

실시간 화면에서 **표적 화면 고정 → 왼쪽 C270 영상의 표적 내부 드래그 → 실측값과 단위 입력 → 현재 결과 기록** 순으로 저장한다. 보정 검증 자료는 다운로드 NPZ만으로 실측을 추정하지 않고, CSV와 표본 ID 또는 프레임 번호를 대조해 대응을 확인한다.
