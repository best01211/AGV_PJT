# 보정 영상 기반 1m 이내 거리 측정 — ±1cm 목표

## 요구와 현재 결과

사용자가 지정한 요구는 **렌즈 중심에서 표적까지 직선거리, 1m 이내, 절대 오차 ±1cm**입니다. 현재 구현과 실험 결과는 이 정확도 기준을 충족하지 못했습니다. 모델을 바꿔 수치가 가까워진 것과 해당 요구를 검증한 것을 구분합니다.

## 실제 개선 시험

기존 Depth Anything Base는 세 표적의 직선거리를 약 0.900/1.392/1.954m로 예측했습니다. 공식 Apple Depth Pro에 보정된 카메라 초점거리를 직접 입력하는 방식을 추가해 동일한 원본/ROI를 비교했습니다.

| 표적 | 실측 | 새 후보 추정 | 절대 오차 | ±1cm 판정 |
|---|---|---|---|---|
| 핸드폰 | 21cm | 25.3cm | 4.3cm | 미달 |
| 과자 포장지 | 43cm | 42.9cm | 0.06cm | 해당 표본 통과 |
| 음료수 | 73cm | 79.1cm | 6.1cm | 미달 |

평균 절대 오차는 약 3.5cm, 최대는 약 6.1cm입니다. 세 표본 중 하나만 ±1cm를 만족합니다. 비교를 보고 모델을 선택한 자료이며 1m 전 구간, 새로운 물체나 집기를 독립 검증한 결과가 아닙니다. 세 점에 새 보정식을 맞춰 통과시킨 결과도 아닙니다.

원본 수치는 `data/depth_comparison/20261103_depthpro/report.json`에 보관합니다. 실측 초점거리 없이 모델이 화각을 예측하게 했을 때는 평균 오차 약 42.5cm로 더 컸습니다. 알고 있는 카메라 파라미터를 반영하는 방식이 이번 데이터에서는 효과가 있었습니다.

## 실시간 처리 방식

```text
JETANK 원본 300×300
 → PDF의 K/D로 왜곡 보정
 → 보정된 K'의 fx/fy를 이용해 가상 카메라의 픽셀 비율 정규화
 → 변경된 가로 크기에 대응하는 실측 focal_px를 Depth Pro에 입력
 → 예측 Z를 원래 보정 영상 좌표 300×300으로 복원
 → K'로 픽셀별 렌즈 직선거리 계산
 → 사용자가 선택한 표적 ROI의 중앙값/분포 표시
```

정규화는 fx와 fy가 비슷한 가상 투영으로 이미지를 바꾸는 좌표 변환입니다. 카메라의 물리적 픽셀 상태를 새로 측정했다고 주장하지 않습니다. 이미지 좌표를 복원한 뒤 직선거리에는 원래 보정된 300×300 K'를 사용합니다. 추가 벽 배율/오프셋은 적용하지 않습니다.

색상 지도도 Z가 아닌 렌즈 직선거리이며 표시 범위는 0~1m입니다. 1m 이상은 같은 먼 색으로 표현하되 실제 수치를 1m로 잘라 저장하지 않습니다. 배열에는 원본 Z와 계산된 직선거리 R을 모두 저장합니다. 중앙 숫자는 Z로 명시하고, 표적 결과에는 R을 우선 표시합니다.

## 실행

```powershell
.\scripts\start-video.ps1
```

`/video`를 강력 새로고침합니다. Depth 시작 → 표적 화면 고정 → 왼쪽 보정 영상에서 물체 안쪽 드래그 → 렌즈 기준 실측 입력 및 기록 순서입니다. 입력 m/cm 환산을 확인합니다. 정면 물체 기록에는 물체 영역 모드가 기본입니다.

기본 `JETANK_DEPTH_ENGINE`은 `depthpro`입니다. 기존 비교 모델은 서버 실행 전에 `JETANK_DEPTH_ENGINE=depthanything`으로 선택할 수 있습니다. 두 모델의 추정값을 같은 보정식에 혼합하지 않습니다. 실행 중 엔진 환경변수를 바꾸는 기능은 없으며 서버 재시작이 필요합니다.

## 새 실행 의존성과 출처

별도 `.depth-venv`에 timm 0.9.16, pillow-heif를 추가했습니다. 기존 GPU torch/torchvision은 재사용합니다. 공식 코드는 `.depth-model/ml-depth-pro`, 가중치는 `.depth-model/checkpoints/depth_pro.pt`입니다. 커밋과 체크포인트 해시는 `config/depth_pro_manifest.json`에 기록했습니다. 모든 영상 추론은 로컬 GPU에서 수행하며 영상을 모델 제공자에게 업로드하지 않습니다.

공식 Depth Pro는 f_px를 주면 추정 화각 대신 그 초점거리를 사용합니다. 이번에 사용한 인터페이스: https://github.com/apple/ml-depth-pro/blob/main/src/depth_pro/depth_pro.py

## 정확도 합격 판정

`depth.nearfield_validation.validate_nearfield`는 1m 이내 표본 각각의 절대 오차를 검사합니다. 평균 오차가 작아도 한 표본이라도 1cm를 넘으면 시험 세트는 미달입니다. 표본을 모두 통과하더라도 전 구간/새 장면 검증이나 집기 허용으로 자동 승격하지 않습니다.

목표는 `config/nearfield_requirements.json`에 저장했습니다. 현 상태의 `full_range_verified`, `usable_for_grasp`는 false입니다. 단일 영상에서 실측이 없는데 ±1cm 오차라고 표시하거나, 분포가 좁다는 이유로 정확하다고 판정하지 않습니다.

## 검증

웹/카메라/지도/거리 API와 요구 판정 테스트 63개, 보정 후처리 테스트 4개가 통과했습니다. 별도로 동일한 실측 표본에서 새 모델의 GPU 추론을 실행했습니다. 코드 테스트 통과는 ±1cm 측정 정확도 통과를 뜻하지 않습니다.

1m 이내 ±1cm를 완성했다고 보고할 수는 없습니다. 현재 자료에서는 카메라 파라미터를 반영해 오차를 줄였지만, 핸드폰/음료수 오차가 남았습니다. 이 오차를 해결하려면 실제 사용 물체와 여러 거리의 대응 깊이 자료로 모델/보정을 검증하거나, 추가 기하학적 기준을 제공해야 합니다. 데이터 없이 임의의 식으로 이 요구를 보장하지 않습니다.
