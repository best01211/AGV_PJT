# JETANK 관제 개발일지 · 1m × 1m 실기 예비 주행

**작업일** 2026-11-18  
**대상** JetBot 실기 관제 웹  
**진행 상태** 실기 서버 반영 완료 · 장애물 우회 주행 실측 대기

## 1. 작업 개요

1m × 1m 시험 공간에서 작업자가 로봇과 목표를 지도에 직접 지정하고, 경로를 확인한 다음 실제 JetBot을 조작할 수 있도록 관제 기능을 확장했다. 전진·후진·회전을 한 동작씩 실행하는 방식과 한 번에 이어서 실행하는 방식을 모두 제공한다. 차체 크기와 가상 장애물을 경로 계산에 반영하고, 목표 위치가 모서리에 가까울 때는 주변에서 도달 가능한 위치를 별도로 표시한다.

## 2. 실기 주행과 보정

| 항목 | 관측 또는 설정 | 적용 |
| --- | --- | --- |
| 10cm 직진 | 바닥에서 약 9cm 이동 | 기존 직진 시간에 10/9를 곱해 거리 보정에 반영 |
| 90° 회전 목표 | 2.95초 구동에서 목표보다 약 10° 덜 회전 | 단일 회전 구동 시간은 기존 장비 상한인 3.00초 이내로 제한. 좌·우 각도 실측은 추가 필요 |
| 전진·후진 | 현재 장비 보정 범위는 한 동작당 9~46cm | 긴 이동은 보정 범위 안의 여러 동작으로 나눠 실행 |
| 위치·방향 갱신 | 모터 구동 시간으로 이동량과 회전량 추정 | 주행 중 지도에서 추정 위치, 바라보는 방향, 이동 상태 표시 |
| 차체 크기 | 20cm × 20cm | 지도에서 격자 두 칸 × 두 칸 크기의 정사각형으로 표시하고, 방향이 바뀌면 차체 그림도 회전 |

첫 직진과 회전의 오차는 작업자가 바닥에서 확인한 값이다. 이후 구현한 장애물 우회의 실제 정지 위치와 회전 각도는 별도로 측정해야 한다.

## 3. 작업자가 사용하는 화면

| 기능 | 사용 방법 |
| --- | --- |
| 로봇 위치 지정 | **지도에서 로봇 위치 지정**을 누르고 실제 차체 중심이 있는 지점을 클릭한다. |
| 로봇 방향 지정 | **지도에서 로봇 방향 지정**을 누르고 차체 앞면이 향하는 쪽을 클릭한다. 비스듬한 방향도 지정할 수 있다. |
| 위치와 시작점 초기화 | **로봇 위치 초기화**는 추정 위치와 방향을 지운다. **시작점 초기화**는 지도에 등록한 시작점만 지운다. |
| 목표 등록과 선택 | **지도에서 목표 위치 지정**으로 지도 좌표를 고르고 이름을 입력한다. 등록한 목표는 목록에서 다시 선택할 수 있다. |
| 목표 수정과 삭제 | 목록의 **수정**에서 이름과 좌표를 바꾸거나 지도에서 새 위치를 고른다. **삭제**로 선택한 목표를 지도에서 지운다. |
| 가상 장애물 등록 | **장애물 추가**를 누른 뒤 사각형의 맞은편 모서리 두 곳을 클릭한다. 장애물 목록에서 삭제할 수 있다. |
| 경로와 명령 확인 | 보라색 점선은 계획 경로, 노란색 점은 경계에 가까운 목표의 근처 도착점이다. **최근 명령**과 현재 상태에서 실행 중인 동작을 확인한다. |
| 주행 실행 | **다음 동작 실행**은 한 동작을 실행한다. **전체 경로 실행**은 전진·후진·회전을 순서대로 이어서 실행한다. |
| 즉시 정지 | **즉시 정지**를 누르면 현재 동작을 멈추고 대기 중인 경로 동작을 취소한다. |

지도 좌표는 cm 단위다. 왼쪽 아래가 `(0, 0)`이고, 오른쪽으로 X, 위쪽으로 Y가 증가한다. 방향은 오른쪽이 0°, 위쪽이 90°다. 지도에서 위치나 방향을 지정하는 조작은 관제 화면의 기준값을 갱신한다.

## 4. 경로 탐색과 연속 실행

1. 현재 차체 중심, 방향, 목표 좌표, 장애물 사각형을 읽는다.
2. 출발점과 목표를 직선으로 연결할 수 있는지 확인한다. 장애물 모서리 주변과 필요한 경유점도 후보로 두고, 연결 가능한 구간 중 이동 거리 합이 가장 짧은 경로를 선택한다.
3. 직선 구간은 이동 방향에서의 정사각형 차체 폭과 장애물 여유 2cm를 적용한다. 제자리 회전은 차체 모서리가 도는 범위를 기준으로 검사한다. 차체가 통과할 수 있는 경로가 없으면 실행을 막는다.
4. 경로를 제자리 회전과 직선 이동으로 바꾼다. 필요하면 후진을 사용해 회전량을 줄이고, 긴 구간은 장비의 거리·회전 보정 범위에 맞게 나눈다.
5. 전체 경로 실행 중에는 관제 화면의 연결 신호를 확인한다. 서버가 약 2초 동안 신호를 받지 못하면 진행 중인 동작을 정지하고 대기 목록을 취소한다.

가상 장애물은 화면에 등록된 사각형을 사용한다. 카메라 Depth나 센서에서 새 장애물을 받아 자동으로 다시 경로를 잡는 기능은 연결 전이다. 회전과 이동은 현재 구동 시간 기준이므로 실기에서는 통로와 최종 정지 위치를 확인한다.

### 재현 사례 · 모서리 목표에서 실행 버튼이 켜지지 않음

| 항목 | 재현 좌표 |
| --- | --- |
| 로봇 시작 위치와 방향 | `(60, 40)cm`, 위쪽 90° |
| 등록한 2차 목표 | `(10, 90)cm` |
| 가상 장애물 | 왼쪽 아래 `(30, 60)cm`, 오른쪽 위 `(50, 80)cm` |
| 계산한 근처 도착점 | `(13, 87)cm`, 등록 목표에서 약 4.2cm |

20cm 차체의 중심이 `(10, 90)cm`에 있으면, 축에 나란히 서 있는 상태에서도 차체가 위쪽과 왼쪽 경계에 닿는다. 이 배치에서는 장애물을 우회하고 기존 목표 좌표까지 접근하는 경로를 찾지 못했다.

원래의 목표 이름과 좌표를 보존하고, 경계에 가까운 목표 주변 8cm 이내에서 도달 가능한 후보를 탐색하도록 변경했다. 같은 지도에서 노란색 도착점 `(13, 87)cm`와 **근처 도착점까지 실행** 버튼이 표시되는 것을 실기 화면에서 확인했다. 자연어로 목표를 지정했을 때 이 근처 도착점을 사용해야 하면 화면에서 확인한 뒤 실행한다.

## 5. 자연어 명령

자연어 입력에서 로봇을 부르는 말, 일부 구어체 어미, 거리 단위와 한글 수 표현을 처리한다. 등록한 장소 이름은 문장 안에서 공백이 조금 달라도 찾는다.

| 작업자 입력 예시 | 처리 결과 |
| --- | --- |
| `젯봇아, 열 센치만 뒤로 빼줘!` | 10cm 후진 |
| `이제 앞으로 10cm만 가줄래?` | 10cm 전진 |
| `앞으로 좀 움직여줘` | 설정된 기본 거리만큼 전진 |
| `방향을 35도로 맞춰줘` | 지도에 표시할 현재 방향을 35°로 지정 |
| `1차 목표 쪽으로 가볼래?` | 등록한 목표 선택 후 유효한 경로 실행 |
| `지금 바로 멈춰줘!` | 현재 동작 정지 및 남은 경로 취소 |

현재 지원 범위는 한 문장에 한 가지 조작이다. 부정문이나 여러 지점을 연달아 말한 문장은 이동 명령으로 실행하지 않는지 모의 시험에서 확인했다.

## 6. 연결 문제와 복구

- 브라우저는 [JetBot 실기 관제](http://127.0.0.1:8011/)에 접속한다. PC의 SSH 터널이 JetBot에서 실행 중인 관제 서버로 요청을 전달한다.
- 연결이 끊겼을 때 PC에서 8011 포트를 듣는 프로세스가 없어 SSH 터널이 종료된 것을 확인했다. 터널을 다시 열고 JetBot 서버의 응답과 기존 목표·경로를 확인했다.
- 재연결 뒤 화면이 끊김 상태로 남아 있으면 새로고침한다. 주행 중에는 관제 화면과 터널을 연 PowerShell 창을 유지한다.
- 목표·장애물·추정 자세는 현재 서버 메모리에 저장한다. 이번 업데이트에서는 기존 좌표를 복원했다. 일반 재시작 후에는 지도와 로봇 자세를 다시 확인한다.

## 8. 다음 실기 시험 항목

- [ ] 같은 바닥과 출력에서 10cm·20cm 전진과 후진을 반복하고 실측 거리와 편차를 기록한다.
- [ ] 왼쪽·오른쪽 회전의 실측 각도와 차체 중심 이동량을 기록한다.
- [ ] 가상 장애물과 실제 장애물 배치를 맞추고, 한 동작씩 통과 여유를 확인한 뒤 연속 우회를 시험한다.
- [ ] 계획한 도착점과 실제 정지점의 차이를 X·Y 방향으로 기록한다.
- [ ] Depth·맵 생성 결과의 좌표계와 관제 지도의 원점·방향을 맞춘 뒤 센서 연동 방식을 검토한다.
