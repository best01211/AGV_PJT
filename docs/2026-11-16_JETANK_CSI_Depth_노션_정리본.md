# JETANK 기본 CSI 카메라 복구 및 양안 Depth 웹 연동

**작업일** 2026-11-16

JETANK의 IMX219 CSI 카메라 두 대를 복구하고, 좌우 영상을 PC의 FoundationStereo 웹 화면에 연결했다. 기존 C270 양안 보정값을 적용한 시험에서 깊이 지도는 표시됐으며, 확인한 프레임의 중앙 영역은 유효 픽셀 0%로 거리 측정이 불가능했다.

## 1. 카메라 복구

1. JETANK `70.12.228.178`의 SSH와 JupyterLab에 접속했다. 카메라 두 대는 `/dev/video0`, `/dev/video1`로 인식됐지만, Argus가 `Failed to create CaptureSession`을 반환했다. V4L2 직접 읽기도 시간 초과가 났다.
2. 호스트 로그에서 `AlreadyAllocated: Device 0 (of 1) is in use`가 반복되는 것을 확인했다. 사용 중인 카메라를 유지해야 했던 시점에는 기존 Jupyter 버퍼의 좌우 정지 프레임을 읽어 확인했다.
3. 재시작 요청 이후 호스트의 `nvargus-daemon`을 재시작했다. 서비스가 `active`이고, 호스트에서 센서별로 새 프레임 3장을 받는 것을 확인했다.
4. Jupyter 컨테이너는 이전 Argus 소켓을 참조해 연결이 거부됐다. `jetbot_jupyter` 컨테이너를 재시작하고 `work/JETANK/Untitled.ipynb`에서 카메라를 다시 초기화했다. 두 카메라 모두 **480×270** 프레임을 갱신했고, 확인 시점에 CSI 0은 약 **28fps**, CSI 1은 약 **31fps**였다.

## 2. 좌우 영상과 Depth 웹 연결

- Jupyter에서 이미 실행 중인 카메라의 프레임 버퍼를 읽고, 좌우 JPEG를 한 응답으로 묶어 `70.12.228.178:8767/pair`에서 PC에 전달했다. 프레임 전송은 작업 PC의 IP로 제한했다.
- 요청에 따라 기존 C270 양안 보정값을 사용했다. 보정 파일의 입력 크기에 맞춰 CSI 영상을 **480×270에서 640×480으로 리사이즈**한 후 좌우 정렬과 깊이 계산을 수행했다.
- PC에서 실행한 FoundationStereo 화면에 **왼쪽 정렬 영상, 오른쪽 정렬 영상, 깊이 지도**가 표시되는 것을 확인했다. 왼쪽 영상에서 측정 지점을 선택할 수 있다. [JETANK 양안 Depth 웹](http://127.0.0.1:8002/)
- 웹 연결은 Jupyter의 카메라 커널 및 프레임 전달 셀과 PC Depth 서버가 실행 중일 때 사용할 수 있다. [JETANK JupyterLab](http://70.12.228.178:8888/lab?)

## 3. 검증 결과

| 입력 및 처리 방식 | 관찰 결과 |
| --- | --- |
| 저장된 C270 영상 4쌍 · FoundationStereo | 실측 40·70·100·100cm에서 41.84·70.71·100.64·100.66cm로 계산됐다. 최대 절대 오차는 1.84cm였다. |
| 현재 CSI 영상 · 기존 C270 보정값 · OpenCV SGBM | 시험 프레임의 전체 유효 픽셀은 1.1%, 중앙 영역은 0%여서 거리를 표시할 수 없었다. |
| 현재 CSI 영상 · 기존 C270 보정값 · FoundationStereo 웹 | 좌우 정렬 영상과 깊이 지도를 표시했다. 확인한 프레임의 중앙 영역은 유효 픽셀 0%로 `측정 불가`가 표시됐다. |

웹 화면에서 검은 영역은 거리 계산에 실패한 픽셀이다. C270 재계산 오차는 저장된 C270 영상의 결과이며, 현재 CSI 조합은 중앙 거리값을 얻지 못해 실측 오차를 계산할 수 없었다.

## 4. CSI 전용 보정에 필요한 작업

1. 현재 장착 상태와 실제 사용할 해상도에서 **내부 코너 14×9 체커보드**가 양쪽에 모두 보이는 좌우 영상을 여러 각도와 위치에서 확보한다. 같은 조건의 저장 영상이 있다면 활용할 수 있다.
2. 체커보드 한 칸의 길이를 mm로 실측한다. `depth/calibrate_csi_stereo.py`에 서로 다른 자세의 영상 쌍을 최소 12개 입력해 CSI 양안 보정 파일을 생성한다. 이 스크립트는 합성 좌표로 계산과 기존 Depth 코드 호환성을 확인했으며, 현재 장착 상태의 실측 보정은 남아 있다.
3. 웹 서버에 CSI 보정 파일을 연결하고 왼쪽 렌즈 중심에서 표적까지 줄자로 잰 거리와 추정값을 비교한다. 거리 오차와 함께 유효 픽셀 비율 및 측정 실패 횟수를 기록한다.
