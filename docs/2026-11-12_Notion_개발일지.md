# 2026-11-12 개발일지 | JETANK 양안 Depth 실시간 측정과 재보정

> Logitech C270 두 대로 실시간 양안 Depth 화면을 구성했다. 40~100cm에서 직선거리 오차 ±2cm를 목표로 검증했으며, 40cm의 측정 실패와 70cm의 반복 오차가 남아 있다.

## 1. 실시간 양안 Depth 화면

- JETANK에 USB 카메라 두 대를 연결하고 렌즈 중심 간격을 **100mm**로 고정했다. JETANK가 640×480 좌우 원본을 전송하고 PC가 영상 정렬과 Depth 계산을 맡도록 구성했다.
- PC 화면에 **왼쪽 정렬 영상, 오른쪽 정렬 영상, Depth 지도**를 표시했다. 왼쪽 영상에서 표적을 클릭하면 직선거리와 광축 방향 깊이 Z를 확인할 수 있다. Depth 지도의 검은 영역은 거리 계산에 필요한 좌우 대응점이 확보되지 않은 곳이다.
- **실측 비교 저장**은 입력한 거리, 좌우 원본 JPEG, 측정 결과를 `data/stereo_measurements/`에 기록한다. 측정 불가 프레임도 원인을 분석할 수 있도록 저장한다.
- 왼쪽 카메라에서 프레임 읽기에 한 번 실패한 뒤 영상 전송이 멈췄다. 실패 후 1초 뒤 두 카메라를 다시 여는 재시도를 추가하고 PC에서 좌우 영상과 Depth가 들어오는 것을 확인했다.

실시간 화면은 PC에서 실행한다. [JETANK 양안 Depth](http://127.0.0.1:8002/)

## 2. 양안 정렬과 보정

- 마커판은 ArUco 마커 12개를 4열×3행으로 배치했다. 실측 치수는 **마커 한 변 41.5mm, 전체 폭 191mm, 전체 높이 142.5mm**다. 기존 모델의 폭 190mm와의 차이 1mm를 가로 간격 세 곳에 균등하게 반영했다.
- 저장된 40cm 실패 프레임을 기존 보정으로 정렬했을 때 같은 점의 세로 차이가 중앙값 약 **68px**였다. 기존 보정 사진에서는 중앙값 **0px**였다. 현재 촬영과 기존 보정 사이의 정렬 차이를 확인했다.
- 기존 기록 3쌍과 새 촬영 7쌍으로 임시 보정값을 계산했다. 같은 10쌍으로 카메라별 초점거리와 왜곡도 다시 추정했다. 거리 검증에 사용한 사진은 이 10쌍에 포함하지 않았다.

## 3. 독립 사진으로 거리 검증

실측 기준은 **왼쪽 렌즈 중심에서 마커판 중앙까지의 직선거리**다. 아래 값은 마커판 중앙에서 계산한 일반 양안 Depth다.

| 실측 | 폭 191mm를 반영한 임시 보정 | 초점거리와 왜곡을 다시 추정한 보정 |
| --- | ---: | ---: |
| 40cm | 측정 불가 | 측정 불가 |
| 70cm | 66.1cm | 69.7cm |
| 100cm | 98.2cm | 103.2cm |

- **40cm**에서 클릭 영역의 유효 픽셀이 부족했다. 같은 사진에서 마커 모서리를 직접 짝지어 계산하면 **39.5cm**였다.
- **70cm 반복 3쌍**에서 폭 191mm 보정으로 일반 Depth는 **64.4cm, 측정 불가, 64.8cm**였다. 초점거리와 왜곡을 다시 추정한 보정에서는 한 쌍에서 **68.2cm**가 나왔다.
- 실측 렌즈 간격은 **100mm**였고 영상에서 추정한 간격은 약 **85mm**였다. 폭 191mm 보정에서 카메라의 각도와 방향을 유지하고 간격만 100mm로 바꾸자, 100cm 표적이 **115.1cm**로 계산됐다.

**적용 상태** · 재보정 결과는 저장된 사진에서 시험했다. 실시간 화면에는 기존 보정이 적용돼 있다.
