# JETANK 1m × 1m 실기 예비 주행

이번 시험은 JETANK의 직진, 정지, 제자리 회전을 실제 바닥에서 한 동작씩 확인한다. 11월 16일 개발일지에 기록된 웹 관제는 모의 주행용이다. 기록에 나온 0.8m/s와 90도 회전 0.5초는 시뮬레이션의 설정값이다.

## 바닥 배치

평평한 바닥에 테이프로 1m × 1m 경계선을 표시한다. 로봇 본체 중심의 시작점을 한쪽 모서리에서 가로·세로 각각 약 40cm 떨어진 곳에 표시한다. 전방 약 10cm에 A, A에서 왼쪽으로 약 10cm에 B를 표시한다. 로봇의 본체와 돌출부가 제자리 회전 중에도 경계에 닿지 않는지 전원을 끈 상태에서 먼저 확인하고, 필요하면 점의 위치를 조정한다.

```text
             전진 후 왼쪽 회전
       B ◀──────── A
                   ▲
                   │ 짧은 직진
                   │
                   시작
```

## 시험 순서와 기록

| 차례 | 조작 | 현장에서 확인할 값 |
| --- | --- | --- |
| 1 | 궤도가 바닥에 닿지 않게 차체를 받쳐 놓고, 기존 제어 코드로 짧게 전진한 뒤 정지한다. | 두 궤도의 전진 방향, 정지 명령 후 두 궤도 정지 여부 |
| 2 | 바닥의 시작점에서 가장 낮은 유효 출력으로 짧게 직진하고 정지한다. 같은 조건으로 반복한다. | 모터 출력과 단위, 구동 시간, 실측 이동 거리, 좌우 편차 |
| 3 | 본체 중심이 경계에서 충분히 떨어진 위치에서 짧게 제자리 회전 후 정지한다. 시간을 조정해 90도에 가까워지는지 확인한다. | 회전 방향, 구동 시간, 실측 각도, 본체 중심 이동량 |
| 4 | 위 동작이 반복 가능하면 시작점에서 A까지 이동해 멈추고, 왼쪽으로 회전해 B까지 한 구간씩 진행한다. | A·B 정지 위치 오차와 회전 각도 |

사람과 장애물을 시험 면적 밖에 두고, 작업자 한 명이 즉시 접근할 수 있는 물리 정지 수단을 확보한다. 궤도 방향이 예상과 다르거나 정지 후에도 움직이면 바닥 시험을 중단한다. 첫 시험은 가동 시간을 실측해 거리와 각도를 기록하는 단계이며, 10cm 표시는 바닥 기준이다.

## 모터 연동 확인

- 작업공간의 웹 백엔드는 `JETANK_MODE=mock`으로 동작한다. 웹의 즉시 정지 버튼은 모의 로봇을 정지한다.
- 실제 장비의 JupyterLab에서 이전에 사용한 전진·정지 셀을 찾는다. 설치된 환경에 해당 예제가 있다면 제조사 문서의 `basic_motion.ipynb`에서 사용하는 드라이버와 정지 호출을 확인한다. [Waveshare 모터 드라이버 안내](https://www.waveshare.com/wiki/Motor_Driver)
- 웹과 실기를 연결할 때는 확인된 모터 인터페이스와 로봇 측 정지를 먼저 연결한다. 이후 실시간 위치와 방향을 지도 좌표계에서 받아 경로 추종을 검증한다. [11월 16일 개발일지](2026-11-16_Notion_개발일지.md)

## 웹에서 예비 주행 리허설

1. [웹 관제](http://127.0.0.1:8010/)에서 **지도 설정 → 1m × 1m 예비 주행 지도 불러오기**를 선택한다. 웹 지도에서 시작점은 `(0.425, 0.425)m`이고, 오른쪽이 초기 전방이다. 바닥의 시작·A·B를 웹의 **시작점·직진 지점·회전 지점**에 각각 대응시킨다.
2. **10cm 직진**, **왼쪽 90도 회전**, **오른쪽 90도 회전** 중 한 버튼을 누른다. 직진은 현재 로봇이 향한 방향을 따르며 회전은 제자리에서 진행한다.
3. 동작 중 **즉시 정지**를 누르면 남은 이동 또는 회전이 취소된다. 처음 위치와 방향에서 다시 시험하려면 예비 주행 지도를 다시 불러온다.

## JetBot 실기용 웹 페이지 실행

1. JupyterLab에서 [jetbot_trial_web.py](../robot/jetbot_trial_web.py)를 `/workspace/test_move`에 올린다. 기존 `test_move` 모터 드라이버와 거리 보정을 사용한다.
2. JetBot의 JupyterLab 터미널에서 아래 명령을 실행한다. 명령을 실행한 터미널은 열어 둔다.

   ```bash
   cd /workspace
   python3 -m test_move.jetbot_trial_web --live
   ```

3. Windows PowerShell에서 아래의 `YOUR_JETBOT_USER`를 기존 SSH 계정으로 바꿔 실행한다. 이 터미널도 열어 둔다.

   ```powershell
   ssh -N -L 8011:127.0.0.1:8011 YOUR_JETBOT_USER@70.12.231.81
   ```

4. [실기 예비 주행 페이지](http://127.0.0.1:8011/)에서 **실제 JetBot 제어** 표시를 확인한다. 먼저 **즉시 정지**의 응답을 확인한 뒤 직진 또는 회전 버튼을 한 번씩 누른다. 종료할 때는 **즉시 정지**를 누르고 JupyterLab 터미널에서 Ctrl+C로 서버를 닫는다.

직진 10cm 명령에서 실측 9cm가 나와, 기존 `duration_for_cm(10)`에 `10/9`를 곱한 **1.475초**를 적용했다. 2.95초 회전에서는 목표보다 약 10도 덜 돌았다. 단순 비례 보정값은 약 3.32초지만 기존 모터 코드의 단일 회전 상한에 따라 **3.00초**를 적용했다. 양쪽 회전의 실제 각도와 직진 거리는 바닥에서 다시 측정한다.

버튼과 자연어 입력은 같은 동작을 실행한다. `앞으로 10cm 가줘`, `왼쪽으로 90도 돌아줘`, `오른쪽으로 90도 회전해줘`, `정지해줘`를 한 문장씩 보낼 수 있다. 이 페이지는 시간으로 각 동작을 제한한다. 로봇 위치와 1m 경계는 현장에서 확인하며 물리 정지 수단을 준비한다.

### 자연어로 거리와 기준점 설정

- `직진 거리를 15cm로 설정해줘`를 보내면 기본 직진 거리가 15cm로 바뀐다. 다음에 `앞으로 가줘`를 입력하거나 직진 버튼을 누르면 그 값을 사용한다. `앞으로 20cm 가줘`는 그 동작에만 20cm를 적용한다. 현재 장비 보정에서 한 번에 설정할 수 있는 정수 거리는 9~46cm다.
- `시작점을 (40, 40)으로 설정해줘`, `A 지점을 (55, 40)에 등록해줘`로 1m 지도에 기준점을 표시한다. 왼쪽 아래가 (0, 0)cm다. `지도 오른쪽 앞에 B 지점 등록`은 B를 (75, 75)cm에 놓는다.
- 기준점은 바닥에 표시할 때 참고한다. 직진 거리 설정과 기준점은 관제 서버를 재시작하면 초기화된다.

### 전진·후진과 추정 위치 표시

1. 실제 로봇 중심의 바닥 좌표를 확인하고 `현재 위치를 (50, 50)으로 설정해줘`처럼 입력한다. 기준점 등록은 로봇 아이콘의 위치를 바꾸지 않는다.
   로봇을 등록된 시작점에 실제로 두었다면 **로봇을 시작점에 뒀어요**를 눌러 같은 위치에 맞출 수 있다.
2. 로봇이 실제로 바라보는 방향을 `방향을 위쪽으로 설정해줘`처럼 입력한다. 지도에서 오른쪽은 0°, 위쪽은 90°, 왼쪽은 180°, 아래쪽은 270°다. 처음 위치를 입력하면 기본 방향은 오른쪽이다.
3. `앞으로 10cm 가줘` 또는 `뒤로 10cm 가줘`를 보낸다. 전진·후진 버튼은 설정한 기본 거리를 사용한다.

아이콘과 좌표는 명령의 구동 시간과 설정된 방향으로 추정한 값이다. 후진은 별도 실측 전까지 전진 보정 시간을 사용한다. 회전은 직전 실측에 기반한 근사값이다. 위치가 어긋나면 로봇을 정지하고 현재 좌표와 방향을 다시 입력한다. 실제 위치 피드백과 목표 지점 자동 이동에는 별도 센서 연동이 필요하다.

지도에서 로봇 앞의 **파란 화살표**는 바라보는 방향, **초록 화살표**는 전진·후진의 이동 방향, **노란 곡선 화살표**는 제자리 회전 방향이다. 후진 중에는 초록 화살표가 로봇 뒤쪽을 향한다. 동작이 끝나면 이동·회전 화살표가 사라진다.

**최근 명령**에서 실행한 동작과 자연어 원문을 확인할 수 있다. 자동 종료 후에도 직전 주행 명령과 종료 상태를 표시한다.

- **로봇 위치 초기화**는 추정 좌표와 방향을 지운다. 다시 표시하려면 바닥에서 좌표와 방향을 확인해 입력하거나, 로봇을 등록된 시작점에 둔 뒤 **로봇을 시작점에 뒀어요**를 누른다.
- **시작점 초기화**는 지도에 등록한 시작점 표시를 지운다. 두 초기화는 정지 상태에서 수행하며 모터를 구동하지 않는다.
