# 정면 물체 거리 측정 수정

최신 변경: 모델의 광축 깊이 Z와 사용자가 확인한 렌즈 중심 직선거리 R을 분리했습니다. 새 물체 기록은 measurements_v4.csv로 저장합니다. 상세 재검토는 `TARGET_DEPTH_REVIEW_20261103.md`를 참고하세요.

## 확인한 상황

실제 영상을 확인했을 때 정면에는 작은 포장 물체와 손, 책상, 배경이 함께 보였습니다. 코드의 측정 대상은 고정된 중앙 20×20 영역이었으며, 그 영역이 사용자가 말하는 물체만 담는다고 보장할 수 없었습니다. 확인 시 Base 원본 추정은 약 1.15m로, 벽 보정식의 입력 범위 1.433~3.158m 밖이라 보정값은 거부됐습니다. 이 관측만으로 물체의 실제 거리는 알 수 없습니다.

근본적인 한계도 남아 있습니다. 나무색 벽의 중앙값에 맞춘 식은 다른 물체의 절대거리를 보정하는 일반적인 식이 아닙니다. 물체 영역 선택은 측정 대상 혼동을 줄이는 변경이며 단안 모델 오차를 제거하거나 집기 정확도를 보증하지 않습니다.

## 사용 방법

1. `/video`를 강력 새로고침합니다.
2. Depth가 표시되면 **표적 화면 고정**을 누릅니다.
3. 왼쪽 렌즈 보정 영상에서 실제 물체의 안쪽을 드래그합니다. 배경과 손을 가능한 한 제외합니다.
4. 선택 영역의 원본 깊이 중앙값과 10~90% 범위를 확인합니다. 분포가 크면 표면이 섞였을 가능성을 표시합니다. 분포가 좁아도 정확한 거리라는 뜻은 아닙니다.
5. 물체 이름과 실제 측정 거리를 입력하고 **현재 결과 기록**을 누릅니다.
6. 다른 장면으로 바꾸려면 **실시간으로 돌아가기**를 누릅니다.

고정하지 않으면 기존 중앙 영역 기록 방식도 유지합니다. 물체 기록에는 벽 보정식을 적용하지 않습니다. 모델 입력 자체를 잘라 다시 추론하지 않고 동일한 전체 프레임에서 계산된 깊이 배열의 선택 영역만 읽습니다.

## 프레임 일치와 기록

- 화면에 표시한 run ID·sequence로 프레임을 고정하고 최대 2분·4개 고정 프레임을 보관합니다. 새 추론이 나와도 같은 영상/깊이/영역으로 기록합니다.
- 중단·재시작·만료 시 고정 프레임은 사용할 수 없습니다. 로봇 정지나 카메라 방향 제어는 수행하지 않습니다.
- 기록은 `data/depth_evaluation/measurements_v3.csv`에 저장하며 ROI 좌표, 원본 모델값, 실측, 모델명, 입력 크기, 원본 프레임을 포함합니다.
- 각 표본의 원본/보정 JPEG와 전체 NPZ 및 ROI 요약 JSON도 보존합니다.
- 벤치마크 도구는 기존 중앙 기록과 v2/v3 파일을 읽고 각 표본의 ROI를 재현합니다. 보정식 작성은 중앙/선택 영역 관측을 무심코 섞지 않도록 검사합니다.

## API

- `POST /api/depth/pin`: 현재 표시된 run_id/sequence의 고정 토큰 생성
- `POST /api/depth/probe`: 토큰과 x/y/width/height로 해당 영역의 원본 추정 요약
- `POST /api/depth/target-measurements`: 같은 토큰·영역과 실측값 기록
- `GET /api/depth/pinned/{token}/{kind}`: 고정된 undistorted/depth JPEG

ROI는 보정 영상의 300×300 좌표이며 최소 4×4, 지도 범위 안에서만 허용합니다. 별도 3D 좌표 변환이나 로봇 기준의 전방 거리로 변환하는 기능은 추가하지 않았습니다.

## 검증

웹/명령/지도/카메라/Depth 및 표적 측정 테스트 59개와 보정 후처리 4개가 통과했습니다. 선택한 영역이 배경 중앙값에 섞이지 않는지, 프레임 갱신 이후에도 같은 표본을 저장하는지, 고정 만료와 잘못된 ROI를 거부하는지 확인했습니다. 거리 정확도와 실제 집기는 별도의 검증 대상입니다.
