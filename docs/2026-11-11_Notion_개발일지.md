# 2026-11-11 개발일지 | C270 렌즈 보정 및 Depth 거리 검증

> JETANK에 연결한 Logitech C270으로 렌즈 보정을 완료하고, 실시간 영상에서 마커 거리와 Depth Pro 추정 영상을 확인했다. 1m 이내 ±1cm는 목표이며, 현재 검증 결과는 촬영 조건과 거리별로 다르다.

## 오늘의 목표

C270의 640×480 원본 영상으로 렌즈 왜곡과 초점거리를 보정한다. 실제 크기를 아는 ArUco 마커판으로 거리 추정값을 실측과 비교하고, 보정된 영상으로 Depth Pro를 실행한다.

## 1. 마커판과 촬영 기능 준비

- 마커판은 ArUco `DICT_6X6_50`의 ID 1~12를 4열×3행으로 배치했다.
- 검은 테두리 바깥 기준으로 마커 한 변은 **41.5mm**, 마커 사이 간격은 **가로 8mm, 세로 9mm**다.
- 영상 화면에 **보정 사진 촬영** 버튼과 저장 장수를 추가했다. 마커 12개가 인식되는 원본 JPEG를 저장하고, 이전 사진과 거의 동일한 프레임은 건너뛴다.
- 원본 프레임은 프로젝트의 `tmp/c270-calibration-captures`에 저장한다.

## 2. C270 렌즈 보정

| 촬영 세트 | 재투영 오차 RMS | 사진을 한 장씩 제외했을 때 가로 초점거리 |
|---|---:|---:|
| 첫 촬영 12장 | 1.05px | 726~759px |
| 두 번째 촬영 12장 | 1.22px | 711~745px |
| 세 번째 촬영 12장 | **0.74px** | **705~717px** |

세 번째 촬영에서는 종이를 평평하게 받치고 판 전체를 여러 각도로 기울였다. 이 세트의 보정값을 `config/c270_calibration.json`에 적용했다. 640×480 원본 기준 초점거리는 가로 **709.28px**, 세로 **703.92px**다. 재투영 오차는 마커 모서리가 영상에서 얼마나 잘 맞는지 나타내며, cm 단위 거리 정확도는 줄자 실측으로 따로 확인했다.

## 3. 실측 거리 검증과 방식 변경

줄자 기준은 **카메라 렌즈 중심에서 6번 마커 중심까지의 직선거리**다. 오차는 추정값에서 실측값을 뺀 값으로 계산했다.

- **6번 마커 단독 계산**에서 실측 30·60·100cm는 각각 28.97·55.75·95.14cm로 추정됐다. 이 세 점으로 계수 `1.056`을 구했지만, 독립 사진의 40·70·90cm 오차는 각각 −0.50·−1.31·−9.38cm였다. 이후 90cm 반복 사진에서는 같은 계수가 오차를 +6.18~+6.88cm로 키웠다.
- **마커판 전체로 거리 계산**하는 방식으로 전환했다. 마커 12개의 모서리 48점으로 판의 위치와 기울기를 계산한 뒤, 판 위 6번 마커의 중심을 카메라 좌표계로 변환한다. 실시간 마커 거리 계산에는 `1.056` 계수를 사용하지 않는다.

| 실측 조건 | 마커판 전체로 계산한 직선거리 | 오차 |
|---|---|---|
| 90cm 재촬영 3장 | 89.49, 89.57, 89.78cm | −0.51~−0.22cm |
| 40·70·100cm 순서로 촬영 | 34.04, 71.11, 100.99cm | −5.96, +1.11, +0.99cm |
| 40cm 재촬영 3장 | 32.40, 34.33, 34.18cm | −7.60~−5.67cm |
| 줄자 끝을 판 가장자리에 댄 사진 | 39.04cm | 6번 마커 중심의 실측값 확인 필요 |

90cm 재촬영에서는 세 장 모두 ±1cm 범위였고, 40cm에서는 큰 오차가 반복됐다. 마지막 사진은 줄자 끝점과 카메라의 계산 대상이 달라 ±1cm 판정에서 제외했다.

## 4. 실시간 영상에서 확인하는 방법

1. [C270 영상 화면](http://127.0.0.1:8001/video)을 연다.
2. RGB 영상 아래 **마커 거리 측정**을 누르면 6번 마커 중심까지의 **직선거리**와 **광축 깊이 Z**가 cm로 표시된다. 마커 12개가 모두 보여야 한다.
3. **카메라 영상 & Depth**에서 렌즈 왜곡을 보정한 영상과 Depth Pro 추정 영상을 확인한다. 작업 시점에 보정 파일을 읽은 Depth Pro가 프레임을 생성하는 것을 확인했다.

마커 거리 계산에는 실물의 크기와 모서리 좌표가 들어간다. Depth Pro는 카메라 한 대의 영상에서 물체의 깊이를 추정하므로, 렌즈 보정을 적용해도 거리 오차가 남을 수 있다. 두 값을 비교할 때는 Depth 화면에서 **6번 마커 안쪽을 표적으로 선택**하고 직선거리끼리 비교한다. 화면 중앙의 Z와 마커까지의 직선거리는 서로 다른 값이다.
