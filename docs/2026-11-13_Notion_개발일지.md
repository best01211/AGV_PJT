# 2026-11-13 개발일지 | JETANK FoundationStereo 적용과 거리 보정

> Logitech C270 두 대를 10cm 간격으로 고정하고, FoundationStereo와 새 거리 보정값을 적용했다. 최신 저장 원본 4쌍을 다시 계산한 결과, 화면 중앙에서 최대 절대 오차 **1.84cm**로 네 쌍 모두 ±2cm를 충족했다.

## 측정 조건

| 항목 | 설정 |
| --- | --- |
| 카메라 | Logitech C270 두 대, USB 연결, 640×480 |
| 렌즈 중심 간격 | 실측 100mm |
| 측정 지점 | 왼쪽 정렬 영상 중앙 `(320, 240)` |
| 비교 기준 | 왼쪽 렌즈 중심에서 화면 중앙이 가리키는 표면까지의 실측 직선거리 |
| 시험 거리 | 40cm, 70cm, 100cm |
| 목표 | 실측 대비 절대 오차 2cm 이하 |

## 1. 영상 연결 복구와 측정 화면 수정

- JupyterLab에서 JETANK의 양안 영상 전송기를 다시 실행했다. PC에서 왼쪽 영상, 오른쪽 영상, Depth 지도가 들어오는 것을 확인했다.
- 화면을 고정한 상태에서도 측정 지점을 클릭할 수 있게 수정했다. 새 좌표의 계산이 끝난 후 저장 버튼을 활성화해 이전 좌표가 저장되는 상황을 줄였다.
- 검증 기준이 화면 중앙이라는 점을 확인했다. 따라서 저장 좌표가 `(320, 240)`인 것은 정상이다. **실측 비교 저장**은 좌우 원본과 거리 기록을 함께 남겨 같은 사진을 다른 설정으로 다시 계산할 수 있게 한다.

## 2. 양안 정렬과 FoundationStereo 적용

- 저장된 좌우 사진 11쌍으로 카메라의 상대 위치와 방향을 다시 보정했다. 별도 사진 3쌍에서 같은 마커의 세로 위치 차이가 **2.2~3.4픽셀에서 0.5~0.7픽셀**로 줄었다.
- NVIDIA의 FoundationStereo 소형 모델 `11-33-40`을 PC의 RTX 5060 Ti에서 실행했다. JETANK는 좌우 영상을 전송하고 PC는 영상 정렬, 시차 추정, 거리 환산을 처리한다.
- 같은 보정과 좌표로 비교했을 때 FoundationStereo는 40cm 중앙 측정 영역의 유효 픽셀 비율을 **약 85%에서 100%**로 높였다. 거리값은 SGBM과 비슷해 환산 오차가 남았다.
- 보정용 11쌍에서 **실측 거리 ÷ 보정 전 거리**의 중앙값으로 거리 환산 계수 **1.0608**을 구해 FoundationStereo 시험 화면에 적용했다. 별도로 남겨 둔 사진 3쌍의 결과는 실측 40·70·100cm에서 각각 **38.65·70.09·99.39cm**였다.

## 3. 최신 촬영 원본 검증

최신 기록 4쌍은 거리 환산 계수를 구할 때 사용하지 않았다. 저장 당시 결과와 같은 좌우 원본을 FoundationStereo 및 계수 1.0608로 다시 계산한 결과를 비교했다.

| 실측 | 저장 당시 표시값 | FoundationStereo 재계산 | 실측 대비 오차 |
| ---: | ---: | ---: | ---: |
| 40cm | 40.93cm | **41.84cm** | +1.84cm |
| 70cm | 72.75cm | **70.71cm** | +0.71cm |
| 100cm 첫 번째 | 110.95cm | **100.64cm** | +0.64cm |
| 100cm 두 번째 | 111.24cm | **100.66cm** | +0.66cm |

100cm에서 저장 당시 약 11cm 길게 나왔던 두 기록의 오차가 재계산에서 **0.7cm 이내**로 줄었다. 이 차이에는 모델과 보정값 변경이 모두 포함된다. 앞서 저장한 일부 100cm 사진에서는 같은 보정으로도 약 112cm가 나왔으며, 이번 합격 범위는 표의 최신 원본 4쌍이다.

## 현재 사용 방법

1. PC에서 [FoundationStereo 시험 화면](http://127.0.0.1:8003/)을 열고 상태 줄에 **FoundationStereo**가 표시되는지 확인한다. 기존 SGBM 화면은 [포트 8002](http://127.0.0.1:8002/)에서 비교할 수 있다.
2. 측정할 표면이 왼쪽 영상의 중앙 사각형 안에 들어오게 놓는다. 줄자로 잰 지점과 화면 중앙이 같은 표면 지점을 가리키도록 맞춘다.
3. **실측 직선거리(cm)**를 입력하고 **실측 비교 저장**을 누른다. 다음 기록은 **다시 재생** 후 새 영상이 표시되면 저장한다.

## 남은 검증

- [ ] FoundationStereo 화면에서 40·70·100cm를 반복 측정해 거리별 최대 절대 오차와 측정 실패 횟수를 기록한다.
- [ ] 무늬가 다른 일반 물체와 움직이는 표적에서 같은 기준으로 확인한다. 최신 저장 원본의 결과만으로 다른 표면이나 움직이는 장면의 정확도까지 판단할 수 없다.
