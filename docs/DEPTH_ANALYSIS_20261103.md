# 2026-11-03 실측 Depth 비교 결과

## 사용 자료

`data/depth_evaluation/measurements.csv`에 기록된 ‘나무색 벽, 중앙’ 실측 4건과 각 행에 연결된 원본 RGB/NPZ를 사용했습니다. 실측 거리는 사용자 입력값입니다. 새 측정을 임의로 생성하지 않았습니다.

첨부 `depth_unvalidated.npz`는 300×300 float32 배열이며 source_sequence=2932, 중앙 추정값 약 3.1018m입니다. CSV의 1.2m 기록은 sequence=2875이므로 같은 관측으로 간주하지 않았습니다. 이 첨부 배열에는 실측 거리 라벨이 없어 정량 비교 표본에 추가하지 않았습니다.

모든 모델을 같은 원본 영상, 같은 렌즈 보정, 중앙 20×20 유효 깊이 중앙값 기준으로 재추론했습니다. Small 294 재추론 결과는 CSV 원본 추정값과 일치했습니다. 보정 영상 JPEG를 다시 입력하지 않고 원본 RGB에 보정을 재적용해 추가 JPEG 저장에 따른 손실을 피했습니다.

|---|---|---|---|

Base/Large의 상세 수치는 `data/depth_comparison/20261103/predictions.csv`가 기준입니다. 위 표는 읽기 위한 반올림입니다.

## 모델·입력 크기별 원본 오차

| 모델 | 입력 | 평균 절대 오차(m) | 거리 순서 역전 쌍 |
|---|---|---|---|
| Small | 294 | 1.7673 | 1 |
| Small | 518 | 1.0854 | 1 |
| Base | 294 | 1.4739 | 0 |
| Base | 518 | 1.1507 | 0 |
| Large | 294 | 1.4213 | 0 |

큰 모델로 변경하는 것만으로 절대 거리 오차는 해결되지 않았습니다. Small은 0.5m와 0.8m의 순서가 역전됐습니다. Base/Large는 이 4개 관측에서는 순서가 일치했습니다. 일반 장면 전체에서 순서가 정확하다는 의미는 아닙니다.

## 다점 보정 후보

Base 294의 중앙 원본 추정값을 대상으로 다음 실험식을 적합했습니다.

```text
실험 보정 거리 = 0.528047 × Base 294 원본 중앙 거리 - 0.447908
```

- 동일한 4점에 맞춘 평균 절대 오차: 약 0.0263m
- 한 점씩 제외하고 나머지 3점으로 적합한 진단 평균 오차: 약 0.0629m
- 같은 진단의 최대 오차: 약 0.1242m

첫 수치는 적합 자료에서의 오차이므로 실제 정확도 성과로 제시하면 안 됩니다. 한 점씩 제외한 진단도 같은 4건으로 모델과 입력 크기를 선택했으므로 독립 검증이 아닙니다. 정밀 집기나 안전 정지에 사용할 정확도가 입증되지 않았습니다.

프로파일은 `config/depth_experimental_profile.json`에 **enabled=false, usable_for_control=false, apply_to_dense_depth=false**로 저장했습니다. 이 식은 나무색 벽 장면의 중앙값 실험 후보이며, 전체 픽셀·다른 물체·관측 범위 밖에 적용하지 않습니다. 현재 웹의 실시간 모델은 기존 Small 원본 출력으로 유지됩니다.

## 다음 검증

우선 같은 카메라·각도·나무색 벽에서 **0.4m, 0.7m, 1.0m**를 새로 기록합니다. 화면에는 Small 추정값이 표시되어도 원본 RGB가 함께 저장되므로 나중에 동일한 Base 294로 재추론할 수 있습니다. 입력한 실측 거리와 표적이 중앙 ROI에 들어왔는지 확인합니다.

새 3건은 이번 보정식 학습에 넣지 않고, 위 계수를 고정한 상태에서 평가합니다. 같은 장면 검증을 통과한 뒤 다른 재질과 배경으로 일반화 검증을 진행합니다. 같은 장면에서조차 오차가 크면 이 전역 보정 방식을 채택하지 않습니다.

## 재현

```powershell
.\.depth-venv\Scripts\python -m depth.benchmark --output data/depth_comparison/20261103
.\.venv\Scripts\python -m depth.calibrate_distance --predictions data/depth_comparison/20261103/predictions.csv --encoder vitb --input-size 294 --output config/depth_experimental_profile.json
```

비교는 공식 Metric Hypersim vits/vitb/vitl 체크포인트와 기존 기록의 4건을 사용했습니다. 체크포인트는 `.depth-model/checkpoints/`에 보관되어 있습니다. 전체 재추론 배열과 요약은 `data/depth_comparison/20261103/`에 있습니다. 이번에 추가한 다점 보정 검증 테스트 3개가 통과했습니다.
