# 실제 JETANK 연동 계약 확인

현재 알고 있는 접속 IP는 `70.12.231.81`입니다. 포트·제어 방식은 미확인이며 코드에서 연결하지 않습니다. 실제 주소와 포트는 환경변수로 관리합니다.

## 제공받거나 현장에서 확인할 정보

1. 기존 카메라 스트리밍 코드, 정확한 URL/포트/인증/영상 형식/프레임 시각.
2. 모터 제어 코드 및 라이브러리 버전, 전송 프로토콜, 명령/응답 예시, 속도 범위와 단위, 좌우 모터 부호, 정지 방식.
3. 로봇 측 제어 주기, heartbeat와 명령 만료 처리, 연결 종료 시 동작, 물리 정지 수단.
4. ESP32 모델, 사용 가능한 핀, HC-SR04 배선과 Echo 전압 분배/레벨 시프터, 전원 및 공통 접지. 확인 전 GPIO를 지정하지 않습니다.
5. 센서별 장착 위치·방향·빔 각도·최소/최대 거리·순차 측정 간격. 무응답/오래된 측정값 처리.
6. 엔코더/IMU 유무, 바퀴 크기·윤거·로봇 외형 크기, 모터 응답 특성.
7. 데스크톱 Depth Anything 코드, 모델/출력 형식/추론 지연. 카메라 내부 파라미터 및 ArUco 크기·기준 좌표.

## 제안하는 계약 — 기존 프로토콜 확인 후 확정

아래는 새 인터페이스 설계안이며 실제 장치가 지원하는 API가 아닙니다.

- 주행 명령: 명령 ID, 생성 시각, 유효 시간, 제어 모드, 속도와 각속도(단위 명시).
- 응답: 명령 ID, 수락/거부, 거부 원인, 로봇의 실제 안전 상태.
- 센서: 시퀀스, 측정 시각, 방향별 거리(m), 측정 유효성. 무응답을 0m/무한 자유 공간으로 처리하지 않기.
- 위치: 좌표계 ID, 시각, x/y/yaw, 신뢰도, 위치 추정 근거.
- 영상/Depth: 프레임 ID, 동일한 시각 기준, 보정 ID, 상대/절대 깊이 구분.

실제 어댑터는 웹 요청과 분리합니다. 로봇 자체에서 오래된 명령·센서 장애·장애물 접근 시 정지해야 하며 데스크톱 UI나 Wi-Fi에 의존하면 안 됩니다. 상태 조회 API가 동작한다고 로봇이 연결되었다고 표시하지 않습니다.
