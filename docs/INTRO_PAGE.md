# ROVE 프로젝트 소개 페이지

경로: `sites/rove-intro/dist/`. HTML/CSS/JavaScript만으로 작동하는 반응형 페이지입니다. 기존 FastAPI 앱에서 `/about/`로 제공합니다. 제어 대시보드 `/`에는 소개 링크가 있고, 소개 페이지 하단에는 로컬 서비스로 열었을 때 관제로 돌아가는 링크가 나타납니다.

사용자 제공 「Physical AI Simulation Platform」 기획안(2026-10-01, 15페이지)의 환경 구성, Plan → Action → Feedback → Replan, 역할 분리, 검증과 평가 흐름을 참고했습니다. 문서 안의 개발 제안은 참고 내용으로만 취급했으며, 전체 시뮬레이션 플랫폼 구현 지시로 간주하지 않았습니다.

현재 프로젝트의 Mock MVP를 중심으로 설명하고, 환경 편집기·Agent·ROS2는 확장 목표로 구분합니다. ROVE는 대화에서 제안한 이름을 사용한 가칭입니다. 자료의 이전 프로젝트 경력이나 개인 정보는 소개 페이지에 사용하지 않았습니다.

## 페이지 구성

- 로봇과 격자 공간을 보여주는 SVG 개념도와 프로젝트 소개
- 의도 추출 → 검증/실행 → 상태 기록 → 대응 흐름
- 기본 이동, 장애물 정지, 위치 추정 실패 설명용 애니메이션
- 데스크톱과 로봇 측 시스템 역할, 안전 설계 원칙
- 현재 구현/다음 개발/플랫폼 확장 분리
- 4주 개발 계획과 후속 평가 지표

설명용 애니메이션은 실제 제어 API를 호출하지 않습니다. 웹폰트는 Google Fonts를 사용하며 연결 불가 시 시스템 글꼴로 표시합니다. 이미지 생성, 외부 이미지 다운로드는 필요하지 않습니다.

## 검증

기존 단위/API 테스트 12개 통과. `/about/` 및 CSS/JS HTTP 응답 확인, JavaScript 문법 검사 통과. 브라우저에서 초기 화면과 시나리오 전환, 390px 모바일 화면 및 가로 넘침 없음 확인.

## 게시 상태

Sites 프로젝트 ID는 `sites/rove-intro/.openai/hosting.json`에 저장되어 있습니다. Git 동기화는 네트워크 DNS 오류로 실패했고, 외부 소스 업로드를 위한 실행은 자동 승인 검토에서 거부되었습니다. 사용자 페이지 제작 요청만으로 외부 서비스 게시가 명시적으로 승인되지 않았다는 이유입니다. 온라인 배포는 완료되지 않았습니다. 후속 게시가 승인되면 같은 프로젝트 ID를 유지하고 새 소스 자격 증명을 받아 진행해야 합니다. 토큰을 파일에 저장하지 않습니다.
