# JETANK 프로젝트 최종 정리본

**기간** 2026-11-03~2026-11-17

JETANK의 좌우 카메라 영상으로 표적 거리를 계산하고 웹에서 실측과 비교할 수 있게 했다. 별도로, 작업자가 웹에서 장소를 선택하거나 한국어로 명령하면 테스트 지도에서 모의 로봇을 움직이는 관제 기능을 구현했다.

| 작업 | 최종 검증 결과 |
| --- | --- |
| IMX219 CSI 양안 정렬 | 별도로 남겨 둔 사진 1쌍에서 같은 마커 모서리의 세로 차이 95백분위가 **65.82 → 2.84px**로 감소 |
| CSI 거리 배율 | 40·70·100cm 유효 검증 3건을 재계산한 평균 절대 오차가 **4.27 → 0.53cm**로 감소 |
| CSI 측정 안정성 | 실측 70cm 7건 중 **오측정 3건, 측정 불가 1건** |
| Depth 처리 속도 | 저장된 40cm 사진 3쌍에서 계산 시간 중앙값 **1.58 → 0.65초**, 실제 웹 확인 1회에서 영상 수신과 계산 합계 **2.19초** |
| 자연어 웹 관제 | 테스트 지도에서 이동·경유·대기·목적지 변경·즉시 정지 확인. 해당 개발일지 기준 전체 테스트 **78개 통과** |

## 2. 최종 CSI 양안 보정값

IMX219 두 대의 촬영 크기는 **480×270**이며, PC 송출에 맞춰 **640×480**으로 리사이즈한 영상에서 보정과 거리 계산을 수행했다. ArUco `DICT_6X6_50`의 ID 1~12를 **4열×3행**으로 배치한 판을 사용했다. 한 마커의 변은 **41.5mm**, 바깥 마커 테두리 기준 배열 크기는 **192.5×144.5mm**였다.

촬영한 13쌍 중 **12쌍으로 파라미터를 계산**하고 **1쌍으로 정렬을 검증**했다. 양안 재투영 RMS는 **0.818px**, 보정에 사용한 쌍의 정렬 후 세로 차이 95백분위는 **2.156px**였다. 별도 검증에서 확인한 **65.82 → 2.84px**는 `rectify_alpha=0` 기준이다. 실시간 화면은 더 넓은 시야를 확보하기 위해 **0.4**를 사용한다.

내부 행렬은 `K = [[fx, 0, cx], [0, fy, cy], [0, 0, 1]]`이다. `fx, fy, cx, cy`는 **640×480 영상 기준 픽셀 단위**다.

| 파라미터 | 왼쪽 CSI 0 | 오른쪽 CSI 1 |
| --- | ---: | ---: |
| `fx` | 508.473968 | 527.712378 |
| `fy` | 672.291878 | 698.055612 |
| `cx` | 351.762615 | 322.536502 |
| `cy` | 223.036598 | 169.714329 |
| `k1` | −0.398830059 | −0.347804495 |
| `k2` | +0.606877805 | +0.213115903 |
| `p1` | −0.000191926 | +0.000584346 |
| `p2` | −0.000592604 | +0.000254007 |
| `k3` | −1.143270269 | −0.216647993 |
| 카메라별 재투영 RMS | 0.708px | 0.826px |

왼쪽 카메라 좌표를 오른쪽 카메라 좌표로 변환하는 식은 `X_right = R × X_left + T`다. 추정한 렌즈 중심 간격 `‖T‖`은 **91.78mm**다.

```text
R = [[ 0.999711475,  0.023018902, -0.006862783],
     [-0.023136656,  0.999577321, -0.017603249],
     [ 0.006454675,  0.017756951,  0.999821498]]

T = [-89.472098, +3.140593, +20.222413] mm
```

`T`는 두 카메라 좌표계 사이의 이동 벡터다. 지면을 기준으로 한 장착 높이 차이는 별도 실측이 필요하다. 표의 파라미터는 문서 표시용으로 반올림했으며 전체 정밀도는 [CSI 보정 JSON](../config/csi_aruco_calibration.json)에 저장했다.

## 3. 실시간 Depth 화면과 처리 속도

- JETANK에서 현재 좌우 JPEG를 PC로 전달한다. 웹에서 보정 전후 영상을 비교하고, **보정 사진 촬영**으로 양쪽에서 ArUco 마커 12개가 검출된 사진 쌍을 저장할 수 있다.
- 양안 정렬 화면은 공통으로 유효한 **640×363** 영역을 표시해 검은 테두리를 제거한다. 클릭 위치는 전체 정렬 영상 좌표로 환산한다.
- **세로 이동만 보기**는 왼쪽 영상을 기본 **−62px** 위로 옮겨 좌우를 같은 **640×480** 크기로 비교한다. 화면에서 값을 조절할 수 있다. Depth 추론에는 CSI 양안 정렬을 적용한다.
- FoundationStereo 입력을 **640×480 → 480×360**으로 줄이고 추론 반복을 **16 → 8회**로 줄였다. 계산한 시차를 원래 픽셀 단위로 환산해 거리 계산에 사용한다. 저장된 40cm 사진 3쌍의 추정 거리 변화는 최대 **0.02cm**였고, 한 사진의 유효 픽셀 비율은 약 **3.4%포인트** 낮아졌다.
- 카메라 미리보기는 Depth 계산과 별도로 갱신된다. 같은 지점을 요청한 여러 탭은 진행 중인 Depth 결과를 공유한다. 왼쪽 영상 정지 사례는 CSI 0을 다시 시작한 뒤 연속 5쌍 모두 좌우 프레임이 바뀌는 것으로 복구를 확인했다.

## 4. 최종 거리 배율과 실측 결과

실측 거리는 **왼쪽 렌즈 중심에서 선택한 표면까지의 직선거리**다. 광축 깊이 Z는 카메라가 바라보는 방향의 깊이다. 화면에서는 클릭 지점 주변 **21×21픽셀**의 유효 거리 중앙값을 표시하고, 유효 픽셀이 **50% 미만**이면 `측정 불가`로 표시한다.

실측 기록 **14건** 중 절대 오차 **30cm 초과 3건**과 **측정 불가 1건**을 거리 배율 계산에서 제외했다. 모두 실측 70cm에서 발생했으며, 오측정 3건은 **약 105.5~106.2cm**로 표시됐다. 유효 10건의 원본을 최종 FoundationStereo 설정으로 다시 계산했다. 이 중 **7건**의 `실측 거리 ÷ 배율 적용 전 추정 거리` 중앙값인 **0.9478587132094086**을 직선거리와 Z에 적용했다.

| 실측 거리 | 배율 적용 전 | 배율 적용 후 | 적용 후 오차 |
| ---: | ---: | ---: | ---: |
| 40cm | 41.99cm | **39.80cm** | −0.20cm |
| 70cm | 74.67cm | **70.77cm** | +0.77cm |
| 100cm | 106.15cm | **100.61cm** | +0.61cm |

표의 세 기록은 거리마다 한 건씩 남겨 둔 검증 자료다. 유효 검증 3건에서 이전 양안 시험 기준인 **절대 오차 2cm 이하**를 충족했다. 70cm에서 발생한 4건의 오측정·측정 불가 문제와 다른 표면 및 움직이는 표적에서의 정확도는 추가 확인이 필요하다.

## 5. 자연어 모의 주행과 웹 관제

- **27열×19행**, 한 칸 **0.25m**의 점유 격자에 남쪽·중앙·북쪽 통로와 격리 구역을 만들었다. 모의 로봇은 상하좌우 **A\***로 경로를 계산하고 모서리에서 제자리 회전한다. 직진 속도는 **0.8m/s**, 90도 회전 시간은 **0.5초**로 설정했다.
- 웹에서 장소나 구역을 선택하거나 자연어로 이동·경유·대기·목적지 변경·예상 시간 조회·주행 취소를 할 수 있다. 경유지 대기 범위는 **1초~5분**이다. 구역이나 장소의 변경 사항은 지도 파일에 저장할 수 있다.
- 통로를 막았을 때 우회하는 동작, 격리 구역 진입 불가, 주행 중과 대기 중 **즉시 정지**, 모호한 명령의 거부를 확인했다. 작업자 표현 **23개**를 API 테스트에 추가했고 해당 개발일지 기준 **78개** 전체 테스트가 통과했다.
- 이 검증은 모의 지도와 모의 로봇에서 수행했다. 실제 주행을 연결하려면 센서 팀의 지도 규격, JETANK의 위치·방향 입력, 회전 및 통과 여유, 장애물 감지와 정지 동작을 실제 장비에서 검증해야 한다.
