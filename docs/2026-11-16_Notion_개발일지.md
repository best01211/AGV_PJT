# 2026-11-16 개발일지 | JETANK 자연어 모의 주행과 웹 관제

> 작업자가 웹에서 장소나 구역을 선택하거나 한국어 문장을 보내면, 모의 로봇이 지도에서 경로를 계산해 이동한다. 경유지 방문, 지정 시간 대기, 목적지 변경, 주행 취소를 검증했다.

## 작업 배경

- 팀에서 카메라 Depth 측정 성공을 공유했고, 센서 기반 지도 생성은 다른 팀원이 진행 중이다.
- 오늘은 완성된 지도를 입력으로 받는다고 가정해 **명령 해석 → 경로 계산 → 모의 주행 → 화면에서 확인** 흐름을 검증했다. 주행 시험에는 미리 만든 점유 격자 지도를 사용했다.

## 1. 모의 주행과 테스트 지도

- 테스트 지도를 **27열 × 19행**, 한 칸 **0.25m**로 구성했다. 벽을 통과하는 남쪽·중앙·북쪽 통로와 미확인 칸, 경로가 끊긴 격리 구역을 넣었다.
- 여러 통로를 연결한 뒤 목적지에 따라 다른 통로를 이용하는지 확인했다. 남쪽 통로를 지도에서 차단한 시험에서는 중앙 통로로 우회했고, 격리 구역으로는 경로가 없다는 응답을 확인했다.
- 초기에는 Theta*로 대각선이 포함된 경로를 시험했다. 실기에서 구현할 동작을 단순화하기 위해 최종 모의 주행은 **상하좌우 A* 경로와 제자리 회전**으로 전환했다. 로봇은 모서리에서 위치를 유지하며 방향을 돌리고 다음 직선 구간으로 출발한다.
- 모의 직진 속도는 **0.8m/s**, 90도 회전 시간은 **0.5초**로 설정했다. 예상 소요 시간에는 직진, 제자리 회전, 지정한 경유지 대기를 반영한다.

## 2. 작업자용 웹 화면과 구역 관리

- 장소와 구역을 별도 이동 목록에 배치했다. 버튼으로 바로 이동하거나 문장으로 여러 지점을 방문할 수 있다. 상단에는 주행 상태, 현재 목적지, 빨간 **즉시 정지** 버튼을 배치했다.
- 지도에서 **색칠된 면과 흰색 원**은 구역과 그 도착 지점, **초록색 점**은 개별 장소, **파란 선**은 남은 경로를 표시한다.
- **장소 및 구역 관리**에서 장소와 구역을 등록하거나 삭제할 수 있다. 새 구역은 통행 가능한 칸 두 개 이상으로 지정하며, 처음 선택한 칸을 도착 지점으로 사용한다.
- 구역을 삭제하면 색칠된 영역과 도착 지점이 함께 삭제된다. 주행에 포함된 목적지나 경유지를 삭제하면 모의 주행을 정지한다. **지도 설정 → 현재 지도 저장**으로 장소와 구역 정보를 지도 파일에 함께 저장할 수 있다.

## 3. 작업자 표현으로 자연어 명령 검증

조사를 생략하거나 구어체를 쓰는 표현을 실제로 입력해, 목적지·경유지·대기 시간을 올바르게 해석하는지 확인했다. 경유지 대기 시간은 **1초~5분**이며, `두 초`나 `1분`처럼 표현할 수 있다.

| 작업자가 입력하는 문장 | 확인한 동작 |
| --- | --- |
| `자재 보관소로 좀 가줘` | 자재 보관소로 이동 |
| `목적지를 충전소로 바꿔줘` | 현재 위치에서 충전소로 경로 다시 계산 |
| `검사 구역 들렸다가 시작 점 간 뒤 충전소로 와줘` | 검사 구역 → 시작점 → 충전소 순으로 경로 계획 |
| `충전소 가서 1초 대기 후 시작으로 이동` | 충전소에서 1초 대기한 뒤 시작점으로 복귀 |
| `검사 구역에서 두 초 기다렸다가 출고대로 가줘` | 검사 구역에서 2초 대기한 뒤 출고대로 이동 |
| `충전소까지 몇 초 걸려?` | 현재 주행을 유지하면서 예상 시간 안내 |
| `격리 구역까지 갈 수 있어?` | 통행 가능한 경로가 없다고 안내 |
| `주행 취소해 줘` | 현재 주행 또는 대기를 종료하고 남은 경로 취소 |

`검사 구역이나 충전소로 가줘`처럼 목적지가 모호한 문장과 `정지 버튼 누르면 멈춰`처럼 조건이 붙은 문장은 거부하고 진행 중인 주행을 유지했다.

## 검증 결과

- 작업자 표현 **23개**를 API 테스트에 추가해 이동, 경유, 대기, 조회, 정지와 거부 동작을 확인했다. 최종 전체 테스트 **78개 통과**.
- 브라우저에서 직각 경로로 검사 구역에 도착하는 모습을 확인했다. 시간 조회, 경유지 대기, 자연어 주행 취소도 직접 시험했다.
- **즉시 정지** 버튼을 이동 중과 경유지 대기 중 각각 눌러 `정지됨`으로 전환되는 것을 확인했다.

## 시연 순서

1. [JETANK 관제 화면](http://127.0.0.1:8000/)을 연다. 지도가 비어 있으면 **지도 설정 → 복잡한 테스트 맵 불러오기**를 선택한다.
2. `검사 구역에 가서 2초 기다렸다가 출고대로 이동해줘`를 보낸다. 직각 경로와 로봇의 회전, 검사 구역 대기, 출고대 도착을 확인한다.
3. `충전소까지 몇 초 걸려?`를 보내 예상 시간을 확인한다. 새 이동을 시작한 후 **즉시 정지**를 눌러 경로 취소를 확인한다.

## 다음 연동에 필요한 작업

- 지도 생성 팀과 점유값, 해상도, 원점, 좌표계, 시작점, 목적지 및 구역의 전달 형식을 맞춘다.
- 지도와 같은 좌표계에서 로봇의 실시간 위치와 방향을 받아야 실제 출발 위치에서 경로를 계산할 수 있다.
- 실제 JETANK에서 직진과 90도 회전의 오차, 로봇 외형을 반영한 통과 여유, 장애물 감지 및 정지 동작을 검증한다. 오늘 검증 범위는 테스트 지도와 모의 로봇이다.
