# 정면 물체 3건 재검토: Z와 렌즈 직선거리 구분

## 확인한 데이터

선택 ROI와 NPZ를 재계산한 중앙값은 CSV prediction_m과 일치합니다. 프레임 번호도 2950(핸드폰), 3214(포장지·음료수)로 정확히 대응합니다. 따라서 저장 대상이 바뀌거나 ROI 좌표가 어긋나서 생긴 오차로 보이지 않습니다.

사용자는 0.21/0.43/0.73m가 **렌즈 중심부터 물체까지의 직선거리**라고 확인했습니다. 기존 화면/CSV는 모델의 카메라 광축 방향 깊이 Z와 비교했으므로 물리량이 달랐습니다. 공식 point-cloud 예제도 출력값을 Z로 사용합니다: https://github.com/DepthAnything/Depth-Anything-V2/blob/main/metric_depth/depth_to_pointcloud.py

보정 영상의 내부 행렬 K'를 사용해 각 픽셀에서 다음을 계산합니다.

```text
X = (u - cx) / fx × Z
Y = (v - cy) / fy × Z
렌즈 직선거리 R = sqrt(X² + Y² + Z²)
```

ROI 전체의 Z 중앙값에 단일 배율을 곱하지 않고, 유효 픽셀마다 R을 구한 뒤 중앙값과 분포를 계산합니다. 보정 영상의 ROI이므로 원본 K가 아닌 NPZ에 저장된 보정 후 K'를 사용했습니다.

| 물체 | 사용자 실측 R | 모델 Z 중앙값 | 변환한 모델 R 중앙값 | R 오차 |
|---|---|---|---|---|
| 핸드폰 | 0.210m | 0.784m | 0.900m | +0.690m |
| 과자 포장지 | 0.430m | 1.344m | 1.392m | +0.962m |
| 음료수 | 0.730m | 1.771m | 1.954m | +1.224m |

R로 변환하면 Z 이상이므로 이 변환은 수치를 맞추는 보정식이 아니며 모델 오차를 감추지 않습니다. 물리량을 맞춰도 큰 오차가 남았습니다. 근거리 물체에서 현재 모델의 절대거리 성능은 부족합니다.

## 추가 진단

동일 ROI로 Small/Base/Large, 입력 294/518을 비교했습니다. Z를 입력된 실측값과 그대로 비교하는 초기 진단에서 가장 낮은 오차도 Base 518 평균 약 0.679m였습니다. 이 수치는 Z/R 기준을 맞춘 최종 정확도 성과가 아닙니다. 어떤 후보도 원본 출력이 실측에 충분히 근접하지 않았습니다.

Base 294에서 원본 영상, 왜곡 보정 영상, K의 fx/fy 차이를 영상 비율 변형으로 가정한 입력도 진단했습니다. 영상 비율 변경의 과대추정은 일부 감소했으나 해결되지 않았고, 실제 비정사각 픽셀이라는 증거도 없어 실시간 전처리를 변경하지 않았습니다. 다른 가설 입력 결과는 `data/depth_comparison/20261103_targets/projection_diagnostic.json`에 보관합니다.

## 코드 변경

- 선택 ROI 결과에 광축 깊이 Z와 렌즈 직선거리 R을 별도 반환합니다.
- 새 물체 기록은 `measurements_v4.csv`에 저장하며 `distance_kind`, 원본 Z, 변환한 R을 함께 저장합니다. 기본 입력은 사용자가 확인한 `camera_ray_range`입니다. API의 `optical_z`는 해당 종류의 실측일 때만 사용합니다.
- v3 및 기존 중앙 기록은 덮어쓰지 않습니다. 기존 v3 3건의 측정 기준 확인은 이 보고서와 `ray_range_review.json`에 남겼습니다.
- 벤치마크에는 이전 기록의 기준을 명시할 수 있는 `--assume-distance-kind camera_ray_range` 옵션을 추가했습니다. 이미 distance_kind가 있는 기록은 그 값을 사용합니다. 기준을 모르는 벽 기록에 일괄 적용하지 않습니다.
- 보정 프로파일 생성 시 Z와 R 기록 혼합을 거부합니다. 나무색 벽 보정을 새 물체에 적용하지 않습니다.

## 이번 첨부

Downloads의 `depth_unvalidated.npz`는 source_sequence=3865, Base 294 출력입니다. 원본 깊이 중앙값은 약 3.177m, corrected_center_m은 NaN입니다. 이 프레임은 위 실측 ROI 프레임과 다르므로 세 물체 기록에 억지로 연결하지 않았습니다. 세 물체의 정확한 대응 원본은 서버에 저장되어 있어 해당 자료로 검토했습니다.

## 결론과 한계

현재 검증에서는 정면 물체의 절대거리가 정확하다고 볼 수 없습니다. 물체당 한 거리씩뿐이므로 재질과 거리의 영향을 분리할 수도 없습니다. 이 3점을 고차식으로 통과시키거나 음수·범위 밖 값을 잘라 집기에 충분하다고 표시하지 않습니다. 이번 수정은 측정 물리량을 올바르게 맞추고 오차를 확인한 단계입니다. 추가 학습이나 보정 방식 채택 여부는 동일 물체를 여러 거리·장면에서 관측한 별도 검증이 필요합니다.

웹 회귀 테스트 60개와 보정/후처리 테스트 4개가 통과했습니다. 이는 거리 정확도 인증이 아닙니다.
