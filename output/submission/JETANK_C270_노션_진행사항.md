# JETANK C270 거리 추정 진행사항

**2026년 11월 6일 기준**

> JETANK에 연결한 C270의 실시간 영상에서 거리 지도를 생성하고, 선택한 영역의 추정값을 실측값과 함께 저장할 수 있다. 8프레임 중앙값을 사용한 시험 보정은 첫 70cm 검증에서 오차가 0.56cm였으나, 카메라를 다시 배치한 검증에서는 3.46cm였다. **1m 이내 ±1cm 목표는 아직 달성하지 못했다.**

## 지금 사용할 수 있는 기능

- **실시간 영상과 깊이 지도**  
  JETANK의 C270이 640×480 JPEG를 송출한다. PC에서 Depth Pro를 실행하고 웹 화면에 원본 영상과 깊이 지도를 나란히 표시한다.
- **표적 영역 선택과 실측 기록**  
  프레임을 고정하고 표적 안쪽을 드래그하면 선택 영역의 렌즈 기준 직선거리 추정값을 볼 수 있다. 대상 이름과 실측 거리를 입력해 한 장 또는 새 프레임 8장을 기록할 수 있다.
- **중복 없는 8장 수집**  
  JETANK에서 촬영 ID를 붙여 같은 JPEG가 반복 수신돼도 한 번만 집계한다. 묶음마다 프레임별 추정값, 중앙값, 최솟값, 최댓값을 저장한다.
- **세션 간 초점거리 고정**  
  C270 전용 실행 스크립트에서 **609.026px**를 사용한다. 최초 벽면 실험의 추정값을 재현하기 위한 설정이며, 체커보드로 측정한 C270 렌즈 보정값은 아직 없다.

## 실측 결과

나무색 벽면을 대상으로 렌즈 기준점에서 선택한 표면까지의 직선거리를 쟀다. 표의 원본값은 각 묶음 8장의 중앙값이다. 60·80cm 두 묶음으로 1차 보정식을 맞추고, 별도의 70cm 두 묶음에 같은 식을 적용했다.

| 측정 역할 | 실측 | 원본 중앙값 | 보정 중앙값 | 절대 오차 |
| --- | ---: | ---: | ---: | ---: |
| 보정에 사용 | 60.00cm | 49.12cm | 60.00cm | 적합점 |
| 보정에 사용 | 80.00cm | 106.23cm | 80.00cm | 적합점 |
| 첫 검증 | 70.00cm | 79.28cm | 70.56cm | 0.56cm |
| 카메라 재배치 후 검증 | 70.00cm | 87.55cm | 73.46cm | **3.46cm** |

- 첫 70cm 묶음은 개별 프레임 **5/8장**이 ±1cm 이내였다. 최대 절대 오차는 1.32cm였다.
- 재배치 후 70cm 묶음은 **0/8장**이 ±1cm 이내였다. 최대 절대 오차는 4.35cm였다.
- 별도의 70cm 묶음 하나는 초점거리 설정이 **840.472px**로 달랐다. 표의 보정식 검증에는 609.026px 묶음만 사용했다.

초점거리를 고정한 상태에서도 70cm 두 묶음의 보정 중앙값이 **2.90cm** 달랐다. 현재 보정식은 같은 설정의 벽면 기록에서 시험값으로 표시한다. 로봇 주행이나 집기에 필요한 거리 정확도는 별도로 검증해야 한다.

## 실행 및 데이터 위치

JETANK에서 C270 송출을 시작한 후 PC 프로젝트 폴더에서 다음 명령을 실행한다. 카메라 주소가 바뀌면 `-CameraUrl`로 현재 주소를 지정한다.

```powershell
.\scripts\start-c270.ps1
```

[C270 Depth 화면](http://127.0.0.1:8001/video)에서 **Depth 시작 → 표적 화면 고정 → 영역 선택 → 실측값 입력 → 새 프레임 8장 기록** 순으로 진행한다. 이 화면은 추론 서버를 실행한 PC에서 접속한다.

| 프로젝트 내 위치 | 내용 |
| --- | --- |
| `robot/c270_snapshot.py` | C270 영상과 촬영 ID 송출 |
| `scripts/start-c270.ps1` | PC 서버와 고정 초점거리 설정 |
| `data/depth_evaluation_c270/measurements_v4.csv` | 한 장씩 기록한 실측 원장 |
| `data/depth_evaluation_c270/batches/` | 8장 묶음별 측정 JSON과 깊이 배열 |
| `output/submission/` | 제출용 Word 보고서와 ZIP |
